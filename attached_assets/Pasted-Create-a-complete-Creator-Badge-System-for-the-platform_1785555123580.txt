Create a complete Creator Badge System for the platform.

==================================================
CREATOR BADGE SYSTEM
==================================================

Automatically create two badges in the system:

1. Creator Badge
2. Verified Creator Badge

These badges must be available by default without requiring manual database setup.

==================================================
PERMISSIONS
==================================================

Normal User
- Cannot upload videos.
- Cannot access My Video.
- Upload Video and My Video must NOT appear in the Profile dropdown.

--------------------------------------------------

Creator Badge
- Can ONLY access Upload Video.
- Can upload videos.
- Cannot access My Video.
- Profile dropdown ONLY displays:
  • Upload Video

--------------------------------------------------

Verified Creator Badge
- Can upload videos.
- Can access My Video.
- Profile dropdown displays:
  • Upload Video
  • My Video
- Display a Verified Creator badge beside the username.

==================================================
DATABASE
==================================================

Automatically create the required database fields.

users

creator_badge BOOLEAN DEFAULT FALSE

verified_creator BOOLEAN DEFAULT FALSE

Rules

creator_badge = true
verified_creator = false

→ Creator

creator_badge = true
verified_creator = true

→ Verified Creator
