==================================================
10. CREATE TOP UP
==================================================

Buat endpoint:

POST /api/topup/create

Backend:

1. Authentication user.
2. Validasi amount.
3. Generate order_id unik.
4. Create transaction di Neon.
5. status = pending.
6. Request QRIS dinamis ke JagoPay.
7. Simpan gateway reference.
8. Simpan QRIS URL/data.
9. Simpan expired_at.
10. Return QRIS ke frontend.

Contoh response:

{
  success: true,
  orderId: "...",
  amount: 5000,
  status: "pending",
  qrCodeUrl: "...",
  expiredAt: "..."
}

Gunakan format response sebenarnya dari JagoPay jika berbeda.

12. CHECK PAYMENT
==================================================

Buat:

GET /api/topup/:id/status

Frontend boleh melakukan polling setiap 3–5 detik.

Backend:

1. Pastikan user login.
2. Pastikan transaksi milik user.
3. Ambil transaksi Neon.
4. Jika paid → return paid.
5. Jika expired → return expired.
6. Jika pending → cek JagoPay.
7. Cocokkan pembayaran.
8. Verifikasi pembayaran.
9. Jika valid → credit wallet.
10. Return status terbaru.

Jangan percaya status yang dikirim frontend.

==================================================
14. AUTO CREDIT
==================================================

Ketika pembayaran valid:

BEGIN DATABASE TRANSACTION

1. Lock topup transaction.
2. Pastikan status masih pending.
3. Pastikan gateway_reference belum pernah diproses.
4. Lock wallet.
5. Ambil balance_before.
6. Tambahkan amount.
7. Buat wallet transaction.
8. Update topup menjadi paid.
9. Simpan paid_at.
10. COMMIT.

Jika terjadi error:

ROLLBACK.

==================================================
15. ANTI DOUBLE CREDIT
==================================================

WAJIB idempotent.

Periksa Pembayaran

Gunakan:

- unique order_id
- unique gateway_reference jika tersedia
- database transaction
- row locking
- status checking
- idempotency

Jika:

status = paid

JANGAN credit ulang.
